## Rincian Peta Jalan & Arsitektur Masa Depan (Adopsi FUTURE.md)

Detail rencana teknis dan fungsional pengembangan KilasTugas untuk panduan evaluasi dewan juri:

```
[ Tahap 1: MVP Online Round (Selesai) ] ───▶ [ Tahap 2: Grand Final Sprint ] ───▶ [ Tahap 3: Post-Competition Rollout ]
• AI Magic Breakdown (Gemini Flash)          • AI Syllabus & PDF Reader           • Multi-Tenant Campus Workspace
• Visual Pacing & Progress Ring              • PWA Offline-First (IndexedDB)      • Cross-Device Sync (OAuth)
• Pomodoro Focus Mode & Floating Timer       • Always-On Focus Web Push           • Native OS Notification Daemon
• RFC 5545 iCalendar & Share Blueprint       • Collaborative Group Task Split     • Voice Prompt Decomposition
```

### 1. Ekstraksi Modul & Silabus Dosen Otomatis (*AI Syllabus Reader*)
- **Masalah:** Mahasiswa enggan mengetik ulang manual deskripsi tugas yang rumit dari modul/silabus PDF/DOCX (5–15 halaman).
- **Solusi:** Area unggah berkas modul; backend mengekstrak teks instruksi, tanggal tenggat, dan rubrik penilaian; model AI mengonversinya menjadi sub-tugas harian tanpa input teks manual.

### 2. Progressive Web App (PWA) & Offline-First Engine (*PWA Offline First*)
- **Mekanisme:** Pemasangan ke layar utama ponsel (*Add to Home Screen*) tanpa melalui toko aplikasi.
- **Penyimpanan Lokal:** IndexedDB memungkinkan akses jadwal, checklist sub-tugas, dan timer Pomodoro tanpa koneksi internet. Data otomatis tersinkronisasi kembali ke VPS MariaDB saat perangkat online.

### 3. Timer Background Persisten & Web Push Notification (*Always-On Focus Engine*)
- **Masalah:** Jika tab peramban ditutup atau layar ponsel mati, eksekusi JavaScript berhenti sehingga audio alarm bawaan tidak bersuara.
- **Solusi:**
  - **State Persistence:** Timestamp target tuntas (`endTime = Date.now() + duration`) di `localStorage`. Saat tab dibuka kembali, sisa waktu dihitung berdasarkan jam sistem tanpa reset.
  - **Server-Side Web Push Scheduler (VAPID):** Backend menjadwalkan notifikasi Web Push tepat saat sesi 25 menit tuntas, memicu notifikasi di level sistem operasi meskipun peramban dalam keadaan tertutup.
  - **OS-Level Calendar Alarm Fallback:** Alarm kalender bawaan (-15 menit & 0 menit) lewat berkas `.ics` atau Google Calendar sebagai pengingat cadangan.
