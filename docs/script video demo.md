### Rincian Peta Jalan & Arsitektur Masa Depan (Adopsi FUTURE.md)

Detail rencana teknis dan fungsional pengembangan KilasTugas untuk panduan demo dan evaluasi:

```
[ Tahap 1: MVP Online Round (Selesai) ] ───▶ [ Tahap 2: Grand Final Sprint ] ───▶ [ Tahap 3: Post-Competition Rollout ]
• AI Magic Breakdown (Gemini Flash)          • PDF/DOCX Syllabus AI Extractor     • Multi-Tenant Campus Workspace
• Visual Pacing & Progress Ring              • Collaborative Group Task Split     • Cross-Device Sync (OAuth)
• Pomodoro Focus Mode & Floating Timer       • Always-On Web Push Notifications   • Native OS Notification Daemon
• RFC 5545 iCalendar & Share Blueprint       • PWA Offline-First Engine (IndexedDB)• Voice/Audio Prompt Decomposition
```

#### 1. Ekstraksi Modul & Silabus Dosen Otomatis (*AI Syllabus & PDF Reader*)
- **Masalah:** Menyalin manual instruksi dari modul atau silabus setebal 5–15 halaman memakan waktu dan rentan terlewat.
- **Solusi:** Area unggah berkas modul/silabus; parser backend mengekstrak teks instruksi, tanggal tenggat waktu, dan rubrik penilaian; model inferensi AI langsung mengonversinya menjadi sub-tugas harian tanpa input teks manual.

#### 2. Pembagian Tugas Kelompok Terstruktur (*Collaborative Task Split*)
- **Mekanisme:** Ketua kelompok memasukkan daftar anggota dan peran (Analis, Pengembang, Penulis Laporan). AI membagi porsi kerja secara proporsional sesuai estimasi waktu dan keahlian.
- **Dependensi Tugas:** Dasbor dependensi tugas memastikan alur kerja runtut (contoh: anggota implementasi memulai tugas setelah tahap analisis ditandai selesai).

#### 3. Progressive Web App (PWA) & Offline-First Engine
- **Mekanisme:** Pemasangan ke layar beranda ponsel (*Add to Home Screen*) tanpa melalui toko aplikasi.
- **Penyimpanan Lokal:** IndexedDB memungkinkan pengguna melihat jadwal, mencentang sub-tugas, dan menjalankan timer tanpa koneksi internet. Data otomatis tersinkronisasi kembali ke VPS MariaDB saat perangkat online.

#### 4. Timer Background Persisten & Web Push Notification (*Always-On Focus Engine*)
- **Masalah:** Jika tab peramban ditutup atau layar ponsel mati, eksekusi JavaScript berhenti sehingga audio alarm bawaan tidak bersuara.
- **Solusi:**
  - **Auto-Resume via State Persistence:** Menyimpan timestamp target tuntas (`endTime = Date.now() + duration`) di `localStorage`. Saat tab dibuka kembali, sisa waktu dihitung berdasarkan jam sistem tanpa reset.
  - **Server-Side Web Push Scheduler (VAPID):** Backend menjadwalkan notifikasi Web Push berbasis Service Worker tepat saat sesi 25 menit tuntas, memicu notifikasi di tingkat sistem operasi meskipun peramban dalam keadaan tertutup.
  - **OS-Level Calendar Alarm Fallback:** Sinkronisasi alarm kalender bawaan (-15 menit & 0 menit) lewat berkas `.ics` atau Google Calendar sebagai pengingat cadangan.

#### 5. Peningkatan Arsitektur & Skalabilitas Sistem
- **Queue Worker & Rate Limiting:** Implementasi antrean Redis + Celery/ARQ untuk menangani antrean prompt saat beban trafik melonjak pada musim ujian.
- **Model Quantization & Local LLM:** Dukungan model *open-weight* terkuantisasi (seperti Llama-3.2-3B / Qwen-2.5-Coder) pada server lokal atau VPS berdaya rendah untuk menekan biaya operasional API.
- **Analitik Privasi:** Agregasi tren mata kuliah dengan tingkat prokrastinasi tinggi tanpa menyimpan data identitas pribadi mahasiswa.

1. Kecepatan Bicara: Bicaralah dengan tempo wajar dan artikulasi jelas.
2. Sinkronisasi Tangan dan Suara: Gerakkan kursor dan klik tombol bersamaan dengan kalimat narasi yang sedang dibaca.
3. Slide Roadmap: Pada Bagian 7, tampilkan slide grafis ringkas yang memuat diagram roadmap 3 tahap dan 4 pilar fitur masa depan dari `FUTURE.md`.
